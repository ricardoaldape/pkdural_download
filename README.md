# PKDural — Descargas oficiales

Este repositorio público está reservado para **instaladores y actualizaciones de PKDural Studio**.

## Estado

**En desarrollo. Todavía no hay un instalador público verificado.** No descargues archivos de terceros que se anuncien como versiones oficiales.

## Próximas descargas

Cuando exista una compilación probada, se publicará en la sección [Releases](../../releases) junto con:

- Instalador de PKDural Studio y número de versión.
- Notas de cambios y requisitos del sistema.
- Suma SHA-256 para comprobar la descarga.
- Instrucciones de instalación y actualización.

## Separación de proyectos

El desarrollo y el código fuente se mantienen en un repositorio independiente. Este repositorio de distribución no contiene ROMs de juegos, BIOS de consolas ni código interno de desarrollo.

## Aviso

PKDural es una herramienta de creación de proyectos para GBA. Los usuarios deben aportar sus propios recursos y bases compatibles cuando corresponda.
